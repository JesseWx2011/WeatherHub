# WeatherHub
*This site is a work in progress*

## Hub is where the weather is at!

The vision for WeatherHub is a place where you can get all your weather needs, not just a basic weather forecast app, but more than that.

- A Weather App that has Tropical Weather History, the latest weather information at a location, view mesoscale discussions, see weather archives, all on this site.

## Planned Pages
Here are the planned pages for WeatherHub by v1.0 release.

### Current (*Active Development*)
This page is for looking up weather for a location, seeing weather forecast data, weather alerts and history for a location.

### Severe Wx
This page is for viewing the latest severe weather outlooks, mesoscale discussions, warning and mesoscale discussion archive, and tornado history all across the world. Something like this has been implemented on this website: https://panhandlewx.vercel.app/spc/

### Winter
This page is for viewing current snow depth across the United States, winter storm history, and winter weather forecasts.

### Tropics
This page is for viewing active tropical systems across the world, a tropical cyclone archive, hurricane information, satellite imagery, and tropical cyclone outlooks and forecasts.

### Camera Monitors
This page is dedicated towards weather camera monitoring for cameras across the world, view the weather action in just a few clicks.
